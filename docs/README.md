## Как работаем

- Одна репа на GitHub, у каждой команды своя часть (см. разбивку в [data-contract.md](data-contract.md#части-стенда-и-владельцы)).
- Данные сквозного кейса меняем только в `src/data/happy-path.json`. Экраны читают его через провайдер данных и не держат своих копий.
- Решение, которое меняет сюжет или контракт, сначала записываем в [decisions.md](decisions.md), потом правим код.
- Офлайн-файл для стенда пересобирается командой `npm run build:kiosk` и коммитится вместе с изменениями.
