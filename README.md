# DemoStandAIJ

Демо-стенд AI Journey: полный цикл разбора обращения в Антифроде с агентами.

Заставка-конвейер → АРМ Обращений (агент-ассистент) → Разбор проблемы данных (4 агента) → RCA → Обновление условий → АРМ Аналитика → назад в очередь.

Три подготовленных кейса в очереди:

| Обращение | Путь |
|---|---|
| DEMO-204817 · пустой device_id | разбор данных → RCA (таймаут fingerprint-service) → условия → правило |
| DEMO-204816 · нет MCC | разбор данных → поле опциональное → правило |
| DEMO-204815 · знакомый шаблон | сразу к правилу |

Все данные вымышленные и лежат в `src/data/journey.ts` и `src/data/scenarios.ts`.

## Запуск

```
npm install
npm run dev          # разработка, http://localhost:5173
npm run build:kiosk  # пересобрать офлайн-файл dist-kiosk/antifraud-demo.html
```

Готовый офлайн-файл `dist-kiosk/antifraud-demo.html` лежит в репозитории: открывается двойным кликом в браузере, без сервера и интернета.

Без касаний 2 минуты стенд возвращается на заставку. Долгое нажатие (2 с) в левом нижнем углу заставки открывает панель оператора.

Источник данных переключается через `VITE_DATA_PROVIDER=remote|mock` (по умолчанию mock).
