# DemoStandAIJ

Демо-стенд AI Journey: полный цикл разбора обращения в Антифроде с агентами.

Заставка-конвейер с маскотом-фродом → АРМ Обращений (агент-ассистент) → Разбор проблемы данных (4 агента) → Рабочий чат (запуск RCA) → RCA → Обновление условий → АРМ Аналитика (описание правила) → Отчёт об эффективности → назад в очередь.

Задачи, решения, сторилайн и контракт данных для совместной разработки — в папке [`docs/`](docs/README.md).

Три подготовленных кейса в очереди:

| Обращение | Путь |
|---|---|
| DEMO-204817 · пустой device_id (хэппи-пасс) | разбор данных → чат → RCA (таймаут fingerprint-service) → условия → правило → отчёт |
| DEMO-204816 · нет MCC | разбор данных → поле опциональное → правило → отчёт |
| DEMO-204815 · знакомый шаблон | сразу к правилу → отчёт |

Все данные вымышленные. Сквозной кейс DEMO-204817 — единый JSON `src/data/happy-path.json` (структура в [`docs/data-contract.md`](docs/data-contract.md)), фоновая очередь и два дополнительных кейса — в `src/data/journey.ts` и `src/data/scenarios.ts`.

## Запуск

```
npm install
npm run dev          # разработка, http://localhost:5173
npm run build:kiosk  # пересобрать офлайн-файл dist-kiosk/antifraud-demo.html
```

Готовый офлайн-файл `dist-kiosk/antifraud-demo.html` лежит в репозитории: открывается двойным кликом в браузере, без сервера и интернета.

Без касаний 2 минуты стенд возвращается на заставку. Долгое нажатие (2 с) в левом нижнем углу заставки открывает панель оператора.

Источник данных переключается через `VITE_DATA_PROVIDER=remote|mock` (по умолчанию mock).
